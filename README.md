# Monitoreo de humedad de suelo
Proyecto docente para organizar un analisis de hum de suelo en parcelas agrícolas

## Propósito
Explorar cómo varía la humedad del suelo entre parcelas y fechas de muestreo.

## Pregunta de trabajo
¿Cómo cambia la humedad del suelo entre las parcelas consideradas?

## Variables de interés
- parcela: identificador ficticio de la unidad de muestreo
- fecha: fecha de observación
- humedad_suelo: medición de humedad (unidad por definir según el instrumento)

## Datos
En esta práctica no se incluyen datos reales. Antes de usar datos, documentaremos su fuente, licencia, unidades y método de medición.
